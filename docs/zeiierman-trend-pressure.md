# Zeiierman Trend Pressure

Native TypeScript behavioral port of Zeiierman's Pine Script v6 **Zeiierman Trend Pressure (Zeiierman)**, © Zeiierman, licensed [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). This implementation is attributed, non-commercial, and shared under the same license terms. It is not affiliated with or endorsed by Zeiierman or TradingView.

Add **Trend Pressure** from Indicators for the oscillator pane. Open **Floating → Trend Pressure** to see the same Z-Pulse, Z-Trend and Pressure Core in a draggable, zoomable window. When an indicator is present, the window borrows its settings (even when the pane is hidden); otherwise it uses the published defaults. The window is closed by default so existing workspaces do not gain another panel. Use the window's plus/settings button to add or edit the indicator.

The calculation follows the supplied script's weighted range readings, stochastic pulse, directional persistence, efficiency-based trend update, two-horizon price pressure and stateful exhaustion confirmation / release. Upper/lower starts, active states, releases and crosses are derived from the same bar-aligned result as the pane. Price exhaustion boxes (up to the configured maximum) and release markers appear on the main price chart when enabled; the oscillator has the upper/lower zones, equilibrium, pulse, trend, core, signals and an extreme-only gradient. The color and lookback inputs are in the indicator settings.

**Parity boundaries:** This is not a Pine interpreter. It computes on closed history plus the currently forming candle and recomputes on updates; the newest candle can change until it closes. Unlike Pine's `syminfo.mintick`, Atlas uses the selected asset's price increment when available, or `1e-8` otherwise. Chart boxes are SVG overlays rather than TradingView `box` objects, and signal triangles use native cross/circle glyphs; the floating window is a compact view of the oscillator, not a Pine pane. The gradient is rendered with SVG rather than TradingView's `fill`. The four Pine alert conditions (upper/lower release and pulse/trend crosses) are calculated as bar-aligned events but are **not yet offered by Atlas’s custom alarm builder**; no automatic notification is sent for them. No bundled TradingView reference data is claimed; deterministic unit tests cover formula startup, state transitions, bounds and window/pane alignment.
